GEO Audit 대시보드 — MCP 접속 & Raw JSON 수령 가이드

서버: geo-audit-dashboard · 전략 10국 GEO/AI Readability 감사 집계 · 데이터는 월간 감사 시 자동 갱신

한 줄 요약 — 이 MCP 서버는 reports/dashboard_data.json(10국 집계)을 노출합니다. 완전한 raw JSON이 필요하면 get_raw 도구 하나면 됩니다. 파일을 직접 읽어도 동일합니다.

1 MCP 접속 포인트

이미 ~/.claude.json 의 mcpServers 에 등록되어 있습니다. Claude Code를 재시작하면 도구가 활성화됩니다.

서버 이름
geo-audit-dashboard
전송 방식
stdio (표준 입출력 · JSON-RPC 2.0)
실행 명령
/usr/bin/python3 /Users/dubaba/my-geo-project/my-geo-audit/mcp_dashboard_server.py
의존성
없음 (Python 표준 라이브러리만 — pip 설치 불필요)
Claude 내 도구명
mcp__geo-audit-dashboard__<도구>

등록 설정 (참고 — 이미 적용됨)

// ~/.claude.json → mcpServers
{
  "geo-audit-dashboard": {
    "type": "stdio",
    "command": "/usr/bin/python3",
    "args": ["/Users/dubaba/my-geo-project/my-geo-audit/mcp_dashboard_server.py"],
    "env": {}
  }
}

다른 MCP 클라이언트(Claude Desktop 등)에서도 동일한 command/args로 등록하면 접속됩니다.

2 제공 도구 (5개)

도구인자반환
get_raw—완전한 raw JSON 전체 (10국 × 카테고리 × 항목 + overall). 가공 없음.
list_countries—10국 요약(총점·표본·파싱실패·감사일), 총점 내림차순
get_scorecardcountry한 국가 전체 — 4카테고리 획득률 + 항목별 pass율
get_item_passratescountry?, category?항목별 pass율(약점 순). 필터 가능
get_overall—전체 요약(국가수·총표본·가중 총점평균)

3 완전한 Raw JSON 받아가는 3가지 방법

방법 A — MCP get_raw 도구 (권장)

Claude(또는 MCP 클라이언트)에서 get_raw 를 호출하면 파일 전체가 그대로 반환됩니다.

// JSON-RPC 요청
{"jsonrpc":"2.0","id":1,"method":"tools/call",
 "params":{"name":"get_raw","arguments":{}}}

// 응답 content[0].text 안에 dashboard_data.json 전체가 문자열로 담겨 옴

대화에서는 그냥 "geo-audit 전체 raw JSON 줘" 라고 하면 이 도구가 호출됩니다.

방법 B — 파일 직접 읽기 (MCP 불필요)

서버를 거치지 않고 캐노니컬 파일을 직접 읽는 게 가장 단순합니다.

# 경로
/Users/dubaba/my-geo-project/my-geo-audit/reports/dashboard_data.json  # ~84KB

# 예: 그대로 출력
cat reports/dashboard_data.json

# 예: Python
import json
data = json.load(open("reports/dashboard_data.json"))

방법 C — stdio로 직접 파이프 (스크립트/CI)

클라이언트 없이 셸에서 서버를 직접 호출:

printf '%s\n' \
 '{"jsonrpc":"2.0","id":1,"method":"initialize","params":{"protocolVersion":"2024-11-05","capabilities":{}}}' \
 '{"jsonrpc":"2.0","id":2,"method":"tools/call","params":{"name":"get_raw","arguments":{}}}' \
 | /usr/bin/python3 mcp_dashboard_server.py

4 Raw JSON 스키마

최상위는 countries(국가코드 → 집계)와 overall 두 키입니다. 국가별 구조는 동일합니다.

{
  "countries": {
    "au": {
      "sample_size": 919,          // 감사 URL 수
      "parse_fail_rate": 0.0011,     // HTML 파싱 실패 비율(차단 지표)
      "total_avg": 68.05,          // 총점 평균 / 100
      "max": 100,
      "grade_dist": { "Good":3, "Need Improvement":865, "Poor":51 },
      "date": "2026-07-19",       // 감사일
      "run_file": "au_2026-07-19_run_74cf2c171a29.json",
      "breakdown": {              // 카테고리별 (0~100 정규화)
        "performance":   { "points_avg":58.3,  "max":100, "pass_rate":0.5858 },
        "accessibility": { "points_avg":89.83, "max":100, "pass_rate":0.8983 },
        "seo":           { "points_avg":80.61, "max":100, "pass_rate":0.8036 },
        "ai_readiness":  { "points_avg":60.28, "max":100, "pass_rate":0.6028 }
      },
      "items": {                  // 항목(49개 기준)별 pass율
        "perf_ttfb": { "label":"#1 TTFB < 600ms", "category":"performance",
                       "pass_rate":0.0588, "applicable_n":919 }
        // ... 나머지 항목
      }
    }
    // ... us, uk, de, es, ca, br, mx, in, vn (동일 구조)
  },
  "overall": {
    "countries": 10,
    "sample_total": 7370,
    "total_avg_weighted": 65.19,  // 표본 가중 총점 평균
    "missing": []
  }
}
주의 — breakdown.max 는 항상 100입니다. 각 카테고리 점수는 0~100으로 정규화 저장됩니다 (실제 배점 가중치 performance 25 / accessibility 15 / seo 20 / ai_readiness 40 은 total_avg 계산에만 반영). 카테고리 획득률은 pass_rate 또는 points_avg/100 로 보세요.

5 데이터 갱신 & 운영

생성기
gen_dashboard_data.py → reports/dashboard_data.json
자동 갱신
감사 완료 시 run_render_audit._refresh_report() 에서 자동 재생성
월간 배치
launchd com.geoaudit.monthly · 매월 1일 02:00 (10국 감사 후 갱신)
수동 갱신
/usr/bin/python3 gen_dashboard_data.py
