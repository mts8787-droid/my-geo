# 크롬 웹 스토어 확장 프로그램 등록 가이드

로컬(개발자 모드)에서 사용하는 확장 프로그램을 **공식 크롬 웹 스토어(Chrome Web Store)**에 업로드하여 다른 팀원들이 링크 하나만으로 손쉽게 설치할 수 있도록 배포하는 방법입니다.

---

## 1. 사전 준비사항
1. **GEO Audit 확장 프로그램 ZIP 파일**: 웹 대시보드 우측 상단의 `[확장 프로그램 다운로드]` 버튼을 통해 최신 `geo-audit-extension.zip` 파일을 다운로드합니다.
2. **구글 개발자 계정**: 확장 프로그램을 등록하려면 구글 크롬 개발자 계정이 필요합니다.

---

## 2. 개발자 계정 등록 및 결제 (최초 1회)
구글 계정이 준비되었다면 아래 절차를 따릅니다.

1. [Chrome 웹 스토어 개발자 대시보드](https://chrome.google.com/webstore/devconsole/)에 접속하여 로그인합니다.
2. 개발자 계약에 동의하고, **등록 수수료 $5 (약 7,000원)**를 결제합니다. (평생 1회만 결제하면 이후 계속 무료로 업로드 가능합니다.)
3. 결제가 완료되면 개발자 대시보드가 활성화됩니다.

---

## 3. 확장 프로그램 업로드 (새 항목 추가)

1. 개발자 대시보드 좌측 메뉴에서 **[새 항목 추가 (New Item)]**를 클릭합니다.
2. 업로드 창이 나타나면, 준비해둔 `geo-audit-extension.zip` 파일을 그대로 드래그 앤 드롭하여 업로드합니다.
3. 압축 파일 내부의 `manifest.json` 파일을 자동으로 스캔하여 앱 이름과 기본 설정이 로드됩니다.

---

## 4. 스토어 등록 정보 작성

스토어에 노출될 정보를 작성합니다. 사내용(비공개)으로 쓸 경우 간단하게만 작성해도 무방합니다.

- **설명**: 확장 프로그램에 대한 간단한 설명을 입력합니다. (예: "사내 GEO(Generative Engine Optimization) Audit 및 SSR/CSR, 스키마 검증 도구입니다.")
- **아이콘 및 스크린샷**: 
  - 스토어 아이콘 (128x128 픽셀) 1장
  - 홍보용 스크린샷 (1280x800 또는 640x400 픽셀) 최소 1장 이상 등록 필수
- **언어 설정**: 기본 언어를 '한국어'로 설정합니다.

---

## 5. 개인정보 보호 설정 (권한 설명)

구글 심사를 통과하려면 이 확장 프로그램이 왜 특정 권한이 필요한지 사유를 적어야 합니다.

- **단일 목적**: "웹페이지의 SEO 및 AI 최적화 점수, 스키마 정합성을 분석하는 도구입니다."
- **권한 근거 (Permission Justification)**:
  - `scripting`, `activeTab`: "활성 탭의 페이지 콘텐츠(DOM)를 읽어들여 SSR/CSR 글자 수 비중 및 JSON-LD 스키마의 정합성을 검사하기 위해 필요합니다."
  - `tabs`: "다중 URL 일괄 분석 시 백그라운드에서 탭을 열고 닫기 위해 필요합니다."

---

## 6. 배포 옵션 선택 및 심사 제출

공개 범위를 설정합니다. 사내에서만 제한적으로 사용할 경우 **'비공개(Unlisted)'** 옵션이 유리합니다.

- **공개(Public)**: 누구나 검색해서 설치 가능
- **비공개(Unlisted)**: 검색에는 노출되지 않으며, **설치 링크를 전달받은 사람만 설치 가능** (사내 배포용으로 추천)
- **비공개(Private)**: 지정된 구글 계정 사용자만 설치 가능

모든 설정이 완료되었다면 우측 상단의 **[심사 제출 (Submit for Review)]** 버튼을 누릅니다.

> **💡 심사 소요 시간**
> 구글의 자동/수동 보안 심사가 진행되며, 보통 **1일 ~ 3일** 정도 소요됩니다. 심사가 완료되면 입력하신 이메일로 '게시 완료' 알림이 옵니다.

---

## 7. 팀원 배포
심사가 완료되어 '게시됨(Published)' 상태가 되면 제공되는 **웹 스토어 링크**를 복사합니다.
이후 보안팀이나 파트너사 등 설치가 필요한 사람들에게 링크만 전달하면, 복잡한 로컬 설치 과정 없이 `[Chrome에 추가]` 버튼 하나로 손쉽게 사용할 수 있습니다.
